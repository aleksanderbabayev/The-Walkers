# The Walkers

Минимальное браузерное приложение для исследования города пешком.

## MVP

- Leaflet-карта с тайлами OpenStreetMap.
- Одна активная прогулка, ручные кнопки «Старт» и «Финиш».
- GPS-точки сохраняются в IndexedDB по мере поступления и каждые 5 секунд.
- После «Финиш» начало и конец сравниваются: при расстоянии до 50 м и минимум 4 точках маршрут считается замкнутым и рисуется закрашенная территория. Иначе сохраняется линия маршрута.
- Завершённые маршруты, территории и текущий черновик хранятся локально в браузере.

В MVP нет аккаунтов, сервера, синхронизации, соревнований или фоновой записи.

## Запуск

Геолокация доступна на HTTPS (либо на `localhost` при локальной разработке). Откройте проект через HTTPS-хостинг или запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`. Разрешите странице доступ к местоположению. Leaflet загружается с CDN, карта использует стандартные тайлы OpenStreetMap.

## Хранение и приватность

GPS-маршруты записываются в IndexedDB браузера на этом устройстве. Они не отправляются на сервер приложения. Для показа карты браузер обращается к серверу тайлов OpenStreetMap. Очистка данных сайта удалит локальные маршруты.
