# Инструкция для Codex: проект The Walkers

## Контекст проекта

The Walkers — браузерное приложение, которое помогает одному человеку исследовать город пешком и видеть пройденный маршрут и закрытую им территорию. Это самостоятельный MVP без пользовательских аккаунтов и без backend.

### Согласованные требования MVP

1. Карта на базе OpenStreetMap и Leaflet.
2. Две ручные кнопки: «Старт» и «Финиш».
3. Запись маршрута через браузерный Geolocation API.
4. Промежуточное сохранение точек маршрута в IndexedDB.
5. Проверка замкнутости выполняется только при нажатии «Финиш».
6. Замкнутый контур показывается как закрашенный полигон. Незамкнутый маршрут остаётся линией.
7. Маршруты и территории сохраняются локально на устройстве.
8. Не добавлять аккаунты, сервер, синхронизацию, соревнования, рейтинги, мультиплеер или фоновую запись.

### Принятые технические значения прототипа

- Автосохранение черновика: каждые 5 секунд и после поступления новой точки.
- Удалять GPS-шум: игнорировать точку ближе 4 метров к предыдущей.
- Порог замыкания: расстояние между первой и последней точками не более 50 метров.
- Минимум точек для замкнутого полигона: 4.
- Замыкание определяется только на Finish, не во время прогулки.
- Только vanilla HTML/CSS/JavaScript, Leaflet как единственная библиотека приложения. Без bundler, framework, Turf и сервера.
- Текущий стартовый центр карты: Прешов, Словакия. Кнопка геолокации центрирует карту на текущей позиции.

## Структура

- `index.html`: разметка и подключение Leaflet.
- `styles.css`: адаптивный интерфейс для телефона и компьютера.
- `app.js`: Leaflet, Geolocation API, IndexedDB, запись и завершение прогулки.
- `README.md`: краткое описание и запуск.

Сохраняй архитектуру простой. Не дроби проект на дополнительные слои, пока это не требуется конкретным MVP-багом.

## Запуск и проверка вручную

1. Запусти локальный статический сервер из папки проекта: `python3 -m http.server 8000`.
2. Открой `http://localhost:8000` в браузере. Для телефона используй HTTPS-хостинг, так как геолокация требует защищённого контекста.
3. Убедись, что видны карта OSM, кнопки и список прогулок.
4. Разреши доступ к геолокации и нажми «Старт». Проверь, что появляются GPS-точки и интерфейс показывает активную запись.
5. Обнови страницу во время записи: приложение должно предложить восстановить черновик из IndexedDB.
6. Нажми «Финиш». Для замкнутой прогулки с 4+ точками и концами в пределах 50 м должна появиться залитая территория. Для остальных случаев должна сохраниться линия.
7. Перезагрузи страницу и проверь, что сохранённая прогулка остаётся на карте.

Проверку GPS выполняй на улице или с симулированной геолокацией браузера. Не считать отсутствие реального спутникового GPS в desktop-эмуляторе дефектом приложения.

## Критерии качества и ограничения

- Не терять точки, уже сохранённые в IndexedDB, при ошибке завершения; оставлять черновик для восстановления.
- Не передавать координаты на backend и не добавлять аналитику.
- Не создавать полигон для слишком короткого или незамкнутого маршрута.
- Показывать понятное сообщение при отказе в разрешении геолокации, недоступности GPS или IndexedDB.
- Применять DOM API и `textContent` для пользовательских строк, не вставлять GPS-данные через небезопасный HTML.
- Проверять мобильную ширину экрана, крупные кнопки и понятные статусы.
- Оставлять атрибуцию OpenStreetMap видимой.
- Не добавлять функций за пределами MVP без отдельного запроса владельца проекта.

## GitHub и известное ограничение интеграции

Репозиторий владельца: `https://github.com/aleksanderbabayev/The-Walkers`, ветка по умолчанию `main`.

В этой сессии GitHub-коннектор успешно читает публичный репозиторий и API сообщает о правах пользователя `push`, но попытки записи через Contents API (`create_file`) и Git Data API (`create_blob`) завершились `403 Resource not accessible by integration`. Переподключение GitHub и настройка разрешений «Allow all actions» не устраняют этот отказ. Не проси владельца снова менять разрешения наугад и не утверждай, что код отправлен, пока коммит не подтверждён.

Если GitHub-коннектор по-прежнему отклоняет запись:

1. Разрабатывай и проверяй проект локально в открытой папке Codex.
2. Покажи конкретный текст ошибки интеграции.
3. Используй обычный `git push` из среды, где у владельца настроена GitHub-аутентификация, либо предложи загрузить файлы через GitHub Desktop.
