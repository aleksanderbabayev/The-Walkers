# Prešov administrative boundary

`presov-boundary.geojson` is a local snapshot of OpenStreetMap relation [2320257](https://www.openstreetmap.org/relation/2320257), tagged `boundary=administrative`, `admin_level=8`, and `official_status=sk:mesto`. Retrieved 2026-11-21. © OpenStreetMap contributors, available under the Open Database License (ODbL).

The app intersects saved captured territories with this local boundary, unions the intersected polygons, and measures the result on the WGS84 authalic sphere. With the current boundary snapshot the calculated city area is approximately 70,452,612.4 m². No boundary API is used at runtime.
